动手实验：把知识点落到一次操作里

这一章不只要求你“理解”。你应该至少跑一次命令、打开一次文件、观察一次 state 或 trace。JobAgent 的教学价值在于它是可运行项目，不是架构幻灯片。

工程选择题：什么时候这样做，什么时候不要这样做

新 agent 放在哪个位置？取决于它依赖 JD、company brief、fit score 还是 resume proposal。 是否需要 HITL？如果输出会影响真实申请或外部写入，需要。 是否需要真实 LLM？先 deterministic baseline，再用 provider adapter 替换。

这些问题比答案本身更重要。Multi-agent 工程的成熟度，不在于堆多少框架，而在于你能说清楚每个边界为什么存在、什么时候需要升级、升级会带来什么新复杂度。

行业脉搏：把本章放到 2026 AI infra 里看

Langfuse 在 2026 年公开了 evaluate AI agent skills 的实践：把 prompts 做成 dataset，运行 agent，trace 行为，再迭代 skill。

这给 Capstone 一个更高阶方向：不仅评估业务输出，也评估 agent 是否遵守工程 playbook。

读这些链接时，不要只记产品名。更重要的是把它们映射回本项目：哪些能力已经在 JobAgent 里有教学版，哪些能力属于未来的生产升级。

Langfuse evaluating AI agent skills展示如何用 dataset、trace、experiment 评估 agent skill。AWS AgentCore Evaluations GA生产 agent eval 的托管平台参照。
