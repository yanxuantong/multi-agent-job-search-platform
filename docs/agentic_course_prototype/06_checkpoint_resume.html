直接做实验 课程目录

这一章先解决什么问题

本项目把每次 run 保存为 checkpoint。暂停后，pending_node 记录下一步该从哪里继续。

这让用户可以先看 resume proposal，再决定是否 approve。系统不需要重新解析 JD、重新研究公司、重新评分。

Checkpoint 是未来升级 Postgres、queue-backed worker、LangGraph checkpointer 的本地原型。

办签证时你不希望每补一份材料就重新排队、重新拍照、重新填表。Checkpoint 的价值就是保留已完成步骤，只从缺口继续。

这一章不只要求你“理解”。你应该至少跑一次命令、打开一次文件、观察一次 state 或 trace。JobAgent 的教学价值在于它是可运行项目，不是架构幻灯片。

工程选择题：什么时候这样做，什么时候不要这样做

本地 JSON checkpoint 适合学习，但 hosted free instance 里 state 可能 ephemeral。 生产环境需要 durable store、idempotency key、side-effect record、schema version。 恢复逻辑应该从 node 边界恢复，不应该依赖 Python stack frame 还活着。

这些问题比答案本身更重要。Multi-agent 工程的成熟度，不在于堆多少框架，而在于你能说清楚每个边界为什么存在、什么时候需要升级、升级会带来什么新复杂度。

行业脉搏：把本章放到 2026 AI infra 里看

LangGraph durable execution 文档明确指出，resume 不是从同一行代码继续，而是从合适起点 replay，因此 side effects 要包装、幂等或记录。

这也是 agent workflow 和普通 request/response API 最大的工程差异之一。

读这些链接时，不要只记产品名。更重要的是把它们映射回本项目：哪些能力已经在 JobAgent 里有教学版，哪些能力属于未来的生产升级。
