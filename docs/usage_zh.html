Multi-Agent Job Search Platform 使用文档

这是一份中文使用说明，帮助你把这个项目当作 multi-agent 编排学习样板来跑、看、改。项目当前是零外部依赖的教学版本，不需要 API key，也不会联网或自动投递申请。

1. 这个项目能做什么

输入一份职位描述后，系统会按固定的 agent workflow 依次完成：

职位理解提取公司、岗位、技能、地点、职责等结构化信息。
公司研究基于本地 JD 生成公司简报，并保留未来接入外部来源的位置。
匹配分析把 JD 技能和你的 story bank 做匹配，给出 0 到 25 的 fit score。
简历建议生成 bullet rewrite、cover letter outline、recruiter note。
人工审批默认停在 NEED_USER_APPROVAL，写入 checkpoint，等待你决定是否继续。
投递跟踪和面试准备审批后写 tracker，并生成 technical、behavioral、company prep questions。

2. 安装和环境要求

当前版本只依赖 Python 标准库。你可以直接在项目根目录运行：

cd "/Users/xuantongyan/Documents/jobAgent 2"
python3 -m unittest discover -s tests

如果测试输出类似下面这样，说明环境可用：

Ran 4 tests in 0.012s

OK
为什么不用 pip install?

这个版本刻意不引入 LangGraph、Anthropic SDK、OpenAI SDK 或 MCP SDK。目的是先把 state、graph、HITL、eval、trace 的基本操作模式看清楚。

3. 最常用命令

目标命令预期结果
跑到人工审批点 python3 -m jobagent.cli demo 输出 NEED_USER_APPROVAL，生成 resume proposal、checkpoint、trace。
从 checkpoint 继续 python3 -m jobagent.cli resume <run_id> --approve 继续执行 tracker 和 interview prep，最终输出 COMPLETED。
直接跑完整流程 python3 -m jobagent.cli demo --auto-approve 跳过人工停顿，完成 tracker 写入和 interview pack 生成。
跑离线评测 python3 -m jobagent.cli eval 运行 sample eval suite，检查公司名、技能提取、stop reason、fit score。
测试 MCP-shaped 工具边界 printf ... | python3 mcp_server/career_research_server.py 用 JSON stdin/stdout 模拟 MCP tool 调用。

4. 一次完整使用流程

步骤 1：运行 demo

python3 -m jobagent.cli demo

你会看到类似输出：

{
  "stop_reason": "NEED_USER_APPROVAL",
  "company": "Anthropic",
  "role": "Applied AI Engineer, Agent Reliability",
  "fit_score": 21,
  "pending_node": "tracker",
  "checkpoint_path": ".jobagent/checkpoints/<run_id>.json",
  "trace_path": ".jobagent/runs/<run_id>/trace.jsonl"
}

步骤 2：查看生成物

  • resume_proposal：简历 bullet rewrite、cover letter outline、recruiter note。
  • .jobagent/checkpoints/<run_id>.json：暂停时保存的完整 state。
  • .jobagent/runs/<run_id>/trace.jsonl：每个 graph node 的执行 trace。

步骤 3：审批后继续

python3 -m jobagent.cli resume <run_id> --approve

完成后会新增：

  • tracker_update：投递跟踪记录。
  • interview_pack：技术题、行为题、公司研究题和 story matches。
  • .jobagent/applications.jsonl：本地 tracker 写入结果。

8. 当前版本边界

当前项目是 learning reference，不是生产求职自动化工具。它不会自动申请职位，不会登录 LinkedIn，也不会调用真实 LLM。

  • 公司研究目前只使用本地 JD 文本，未来可接 web search 或公司官网 source。
  • MockLLMProvider 只是 provider 边界示范，未来可以替换为 Anthropic/OpenAI structured output。
  • mcp_server/career_research_server.py 是 MCP-shaped stub，不是官方 MCP SDK 实现。
  • tracker 当前写 JSONL，未来可替换为 Postgres、Notion 或 Google Sheets。
